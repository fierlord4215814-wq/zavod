Установка «Завод»

Технический мастер для сисадмина: проверяет Docker, порты, папки, создаёт production-конфиг, запускает сервисы и проверяет здоровье системы.

1. Проверка окружения

Перед установкой нужен Docker Desktop с Docker Compose. Мастер не меняет бизнес-данные и не создаёт пользователей или заводы.

2. Адрес сервера и порты

Для публичного доступа обязательны оба адреса с одним доверенным HTTPS origin. Без них допускается только частная проверка на 127.0.0.1 или localhost.

3. Папки данных

Сюда будут сохраняться копии сообщений об ошибках: текст, данные автора и вложенные фото/файлы. Просмотр в приложении при этом остаётся. Не выбирайте временные папки или папки синхронизации без отдельной политики backup.

4. Проверка настроек

Проверяем доступность Docker, свободные порты и права записи в папки. Ничего не запускаем до кнопки «Установить».

5. Подготовка установки

Будут созданы новый runtime-конфиг и технические секреты, собраны образы, запущена только БД, затем применены миграции и системная основа. Первый администратор создаётся отдельно.

Секреты не показываются в этом окне. Не отправляйте папку runtime и backup в чат или репозиторий.
