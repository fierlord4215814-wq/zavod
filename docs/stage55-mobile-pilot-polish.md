# Stage 55 — Mobile Pilot Polish / Human Corrections

## Discovery result

Stage55 не потребовал новой модели данных. Все исправления легли на существующие контуры:

- `ShiftPeopleScreen`: текущая смена, следующая смена, будущие смены, доски назначений, профиль из слота.
- `SituationScreen`: рабочий список линий и быстрые действия.
- `PeopleScreen`: каталог людей и read-only профиль.
- `OrdersStockScreen` + `OrdersService`: проценты остатков, списание, runtime visibility.
- `ChatsScreen`: лента внутреннего мессенджера.
- `AdminConfigScreen`: человекочитаемые настройки и пояснение по должностям.

Миграция не понадобилась. Backend guards остаются источником истины.

## Mobile-first fixes

- Вкладка `Текущая` показывает только текущие метрики: всего на смене, свободны сейчас, в работе сейчас, отправлены домой только если такие есть.
- Вкладка `Следующая` показывает плановые метрики: отметились “Я буду”, наёмники, плановые линии, и явно пишет, что текущая смена не затрагивается.
- Вкладка `Будущие` получила компактный план и действие `Открыть план`.
- Вкладка `Прошлые` остаётся архивным режимом.
- На 360px ключевые панели используют карточки, sticky actions и перенос длинных названий.

## Assignment ergonomics

- В рабочей зоне больше нет автоматического назначения первого кандидата в первый слот.
- Мастер выбирает слот, затем сотрудника.
- В линии действия показываются по состоянию: `Вернуть в работу` виден только для остановки/простоя, а `Простой` и `Остановить` только для работающей линии.
- В line dashboard добавлено действие `Статистика линии`, которое ведёт к runtime-сводке внутри текущей карточки.

## People and profile

- В справочнике людей добавлен фильтр `Вне смены`.
- В строке человека показывается короткое ФИО, статус смены и русская роль.
- Профиль стал карточным: аватар, ФИО, роль, отдел, статус, телефон по правам, отдельные секции навыков, заметок и доступов.
- Служебные роли не получают controls назначения, назначаемыми остаются WORKER/CONTRACTOR.

## Stock correctness

- Процент остатка считается от минимального порога: `currentQuantity / minThreshold * 100`, максимум 100%.
- `TAKE` больше не требует обязательный комментарий; если комментарий не указан, движение пишется как `Без комментария`.
- Stage/test stock records скрываются из runtime списка, но история не удаляется.

## Chat polish

- Сообщения группируются по автору и дате.
- Кнопки `Изменить` / `Удалить` больше не торчат в каждом сообщении: они открываются через локальное действие сообщения.
- Список и окно чата остаются в messenger-like layout, вложения идут через существующий guarded preview.

## Admin polish

- Настройки модулей показывают русские названия ключей вместо raw camelCase.
- В `Роли и права` добавлено пояснение: собственные должности/job titles не входят в Stage55 и остаются future, чтобы не создавать половинчатую custom-role architecture.

## Regression checklist

- `stage55:mobile-pilot-polish-regression` проверяет shift timeline, line assignment candidates, line dashboard, stock percent, TAKE без комментария, chat runtime noise, admin access, blocked user denial и отсутствие секретов.
- `stage55:browser-e2e` делает mobile 360px screenshots основных экранов в `docs/stage55-mobile-pilot-polish-screenshots`.

## Future

- Отдельная архитектура custom roles/job titles.
- Более глубокая аналитика линий внутри `Линии`, если потребуется не только сменная runtime-сводка.
- Дополнительные жесты для мобильного чата: reply, reactions, swipe-actions.
