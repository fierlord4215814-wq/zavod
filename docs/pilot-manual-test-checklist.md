# Ручной pilot checklist

## Перед стартом

- Открыть приложение на desktop и телефоне.
- Проверить `/health` и `/version`.
- Убедиться, что используется pilot/dev база, а не production.
- Не выполнять DB reset.
- Все тестовые записи помечать `Stage45` или понятным pilot-маркером.

## Роли

Пройти вход, выбор завода и logout для ролей:

- ADMIN;
- MANAGEMENT;
- MASTER;
- WORKER;
- STORE;
- OKK;
- TECH_HOLOD;
- TECH_KIPIA или TECH_MECHANIC;
- CONTRACTOR_LEAD.

## Mobile 360px

Проверить:

- верхнее mobile-меню;
- нижнюю шторку “Ещё”;
- отсутствие горизонтального overflow;
- читаемость кнопок и модалок;
- уведомления и badge;
- logout/offline индикаторы.

## Основной путь смены

MASTER:

- открыть “Смена”;
- увидеть людей;
- открыть “Линии”;
- открыть dashboard линии;
- открыть “Текущее задание”;
- проверить пустое и заполненное задание;
- открыть safe modal “Зафиксировать простой”;
- создать заявку из простоя;
- проверить, что заявка появилась у адресованной техслужбы;
- проверить уведомление и переход “Открыть”;
- открыть “Пересменка / Журнал”.

WORKER:

- увидеть только свой self-view;
- убедиться, что нет админки, assignment board и management controls.

CONTRACTOR_LEAD:

- проверить доступную подрядную область;
- убедиться, что нет assignment board и управления линиями.

## Заявки и уведомления

- Создать срочную заявку.
- Взять в работу адресованной техслужбой.
- Добавить комментарий.
- Закрыть заявку через safe modal.
- Проверить уведомления автора и исполнителя.
- Проверить “Прочитать всё”.

## Архив и аналитика

- Открыть “Архив”.
- Открыть “Заявки и простои”.
- Проверить вкладки: “Сводка”, “По линиям”, “По отделам”, “По исполнителям”, “Просроченные”, “Детальный список”.
- Нажать “Открыть источник” для заявки.
- Открыть “Файлы и вложения”.
- Проверить, что storagePath не виден.

## Чек-листы

- Открыть “Чек-листы”.
- Создать или выбрать шаблон.
- Запустить guided run.
- Пройти пункты “Да/Нет”, число, комментарий, фото.
- Проверить блокировку “Дальше” при обязательном пустом поле.
- Завершить run.
- Найти run в архиве.

## Фото, камера, вложения

На телефоне проверить:

- заявка / комментарий к заявке;
- ОКК;
- возвраты;
- чек-лист;
- чат;
- архив файлов.

Проверить:

- “Добавить фото или файл”;
- preview;
- удаление до отправки;
- русская ошибка на неподдержанный тип или слишком большой файл;
- камера открывается, если браузер поддерживает.

## ОКК и складские журналы

OKK:

- открыть ОКК;
- создать тестовую запись брака;
- проверить поля таблицы;
- отметить выполнение;
- “Полностью завершён” через safe modal;
- найти запись в архиве.

STORE:

- открыть “Возвраты на производство”;
- создать тестовую запись;
- отметить выполнение;
- завершить через safe modal;
- открыть “Некондиция”;
- открыть “Заказы / Остатки”;
- проверить TAKE/RESTOCK за период в архиве.

## Оттайка

TECH_HOLOD:

- открыть “Оттайка”;
- увидеть производственные линии завода;
- открыть календарь линии;
- проверить красный/зелёный/split день, если есть события;
- поставить на оттайку сегодня без обязательного комментария;
- запустить в работу сегодня;
- проверить лёгкую сводку 30/60 дней.

## Администрирование

ADMIN:

- открыть “Администрирование”;
- проверить заводы;
- открыть Завод 4;
- проверить разделы: пользователи, роли, права, линии, позиции, шаблоны состава, повременщики, настройки;
- открыть safe modal для опасного действия;
- убедиться, что last-admin не ломается.

## Завершение

- Запустить quick pilot gate.
- Запустить fixture hygiene dry-run.
- Cleanup apply выполнять только для явно помеченных Stage/pilot записей.
- Зафиксировать найденные UX/RBAC проблемы отдельно от бизнес-идей.
