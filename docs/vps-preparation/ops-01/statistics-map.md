# OPS01 — конечная карта текущей аналитики

**86/86 видимых value-slots сверены source → independent expected → настоящий HTTP → UI**, ADMIN1440/MANAGEMENT390; дополнительные обратные ширины в filters/menu. Это **46 карточек +40 уникальных detail/table/hero slots**, а не 86 разных бизнес-процессов. В число входят название худшей линии и диагностический статус; повтор одного показателя в «Выводах» не считается новым KPI. Повторяющиеся строки нормализованы к `[*]`, исходные точные IDs не потеряны.

[Полный машиночитаемый реестр](metric-register.json): 648 сохранённых сверок, каждая содержит `METRIC`, `USER_MEANING`, `SOURCE_ROWS`, `SOURCE_MODELS`, `TIME_BASIS`, `FILTERS`, `FORMULA`, `EXPECTED`, `API_ACTUAL`, `UI_ACTUAL`, `STATUS`, actor/dataset/evidence. [Сборщик реестра](metric-register.cjs) только связывает полученные receipts. Независимые определения — [основные](independent.cjs) и [детальные](independent-details.cjs), первичные projections — [primary](primary.cjs). Они не импортируют OpsService, его агрегаты, period/visibility helper.
