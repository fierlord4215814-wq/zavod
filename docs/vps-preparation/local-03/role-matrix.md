# LOCAL-03 — итоговая матрица 14 не-ADMIN ролей

Статусы относятся только к Windows C1 с 57 миграциями и текущей сборкой. Общая [baseline 14 ролей](role-screens.json) подтверждает обычный Edge-вход, меню/главный экран, применимые основные экраны, `ADMIN 403`, чужой завод Б `403`, выход и новый мобильный вход. Снимок baseline сделан **до** исправления People-проекции; для живого присутствия использовать [поздний readback](people-presence-live.json). Эта baseline сама по себе не принимает все capability families. `UI` означает настоящую форму; `HTTP` из browser-context fetch без формы здесь не называется UI. `WS/POLL` помечены по реально наблюдавшемуся экрану, а не по одному кадру.

Guest/blocked/revoked отдельно проверены для собственного MASTER: сохранённый token `403` для восьми archive/handover/file readers, после восстановления нормальный вход; [точный receipt](access-036-sec.json). Чужие отделы и заводы не смешаны; это не автоматический PASS каждой роли.

Причина общего `PARTIAL`, а не `FAIL`: положительные операции и запреты выше сохранены, но требование «хотя бы одна UI-операция для **каждой** существенной effective-capability family» и полный контекстный deny не закрыты по всем 14. Нельзя выводить ROLE PASS из отдельных HTTP200 или меню. Полноценный новый завод для заполнения пробелов сейчас не разрешён.
