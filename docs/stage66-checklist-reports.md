# Stage66 — отчёты по чек-листам, Excel/PDF и сводка смены

## Что закрывает Stage66

Stage66 доводит существующий модуль чек-листов до отчётного контура без создания второго модуля:

- Excel-выгрузка архива выбранного шаблона;
- PDF-отчёт по конкретному запуску чек-листа;
- сводка выполнения чек-листов по смене в интерфейсе;
- PDF-отчёт по смене;
- audit для просмотра/экспорта отчётов;
- проверки RBAC, factory scope и отсутствия служебных путей в ответах.

Миграция не понадобилась: Stage64/65 уже дают архив, журнал, матрицу ответов, строки запусков, вложения и права доступа.

## Excel по шаблону

Экспорт запускается из раздела:

`Чек-листы → Архив → выбранный шаблон → Экспорт в Excel`.

Файл содержит:

- лист `Результаты` — один запуск чек-листа в одной строке;
- фиксированные колонки: дата, смена, линия, сотрудник, статус, время начала/завершения;
- динамические колонки по пунктам шаблона;
- лист `Вложения` — только безопасная метаинформация по фото/файлам;
- лист `Параметры` — завод, шаблон, период, смена, дата формирования.

`storagePath`, токены, секреты и внутренние пути в Excel не попадают.

## PDF запуска

PDF доступен из деталей архивного запуска кнопкой `Скачать PDF`.

Отчёт содержит:

- название чек-листа;
- завод;
- дату и смену;
- линию, если чек-лист был привязан к линии;
- сотрудника;
- статус;
- пункты чек-листа;
- ответы, нормы, комментарии и признаки отклонений;
- небольшие превью фото, если файл доступен и безопасно читается.

Если изображение недоступно, PDF показывает понятную строку вместо служебной ошибки.

## Сводка по смене

В архиве чек-листов добавлен блок `Сводка по смене`.

Он показывает:

- сколько чек-листов ожидалось;
- сколько выполнено;
- сколько не хватает;
- сколько в работе;
- сколько запусков с отклонениями;
- сколько требует ручной проверки.

Расчёт ожиданий:

- `Раз в смену`, `Ежедневно`, `При запуске линии` — один ожидаемый запуск;
- `Каждые N часов` — `ceil(12 / N)` для 12-часовой смены;
- `Еженедельно` и `Вручную` — не считаются строгим долгом смены и помечаются как ручная проверка.

Это не BI-аналитика, а рабочий контроль смены: что должно было быть выполнено и что уже сделано.

## PDF смены

Кнопка `PDF смены` формирует PDF по тем же фильтрам смены.

Отчёт содержит:

- дату и тип смены;
- итоговые счётчики;
- список обязательных чек-листов;
- статусы `Выполнен`, `Не хватает`, `В работе`, `Проверить вручную`;
- комментарии по отклонениям.

## RBAC и безопасность

Backend остаётся источником истины:

- отчёты доступны только через права архива чек-листов;
- завод берётся из выбранного factory context;
- cross-factory доступ запрещён;
- заблокированные пользователи не должны получать отчёты;
- вложения в отчётах используются только через guarded attachment flow;
- `storagePath`, `passwordHash`, токены и секреты не возвращаются.

## Audit

Stage66 пишет audit-события:

- `CHECKLIST_EXCEL_EXPORTED`;
- `CHECKLIST_RUN_PDF_EXPORTED`;
- `CHECKLIST_SHIFT_REPORT_VIEWED`;
- `CHECKLIST_SHIFT_REPORT_EXPORTED`.

В audit не попадают служебные пути к файлам и секреты.

## Ограничения

Чтобы отчёты не превращались в тяжёлую BI-выгрузку:

- период отчёта ограничен безопасным окном;
- количество строк ограничено;
- количество фото в PDF ограничено;
- большие вложения остаются ссылками/метаинформацией, а не встраиваются бесконтрольно.
