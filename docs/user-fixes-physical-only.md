# Пласт 8: проверки только на физическом телефоне

`PHYSICAL_PHONE_GATE: PENDING`. Ни один из следующих пунктов не может быть честно отмечен как PASS браузерной эмуляцией.

| Пункт | Что проверить вручную | Ожидаемый итог |
|---|---|---|
| Установленная PWA | Установить приложение с телефона и открыть с домашнего экрана | standalone shell, вход и навигация работают |
| Камера/галерея | Добавить фото в доступном штатном сценарии, отклонить и снова разрешить permission | понятный retry, фото открывается без утечки пути |
| Микрофон/voice note | Deny → allow → retry и воспроизведение сообщения | input остаётся рабочим, запись не дублируется |
| Push/vibration | Разрешить системное уведомление и получить тестовое разрешённое событие | нет ложного успеха при denied, vibration/push по настройкам ОС |
| Системная клавиатура | Длинная форма, comment, chat и checklist при реальной Android-клавиатуре | поле и sticky action остаются доступны |
| Hardware/gesture Back | Sheet → modal → detail → root screen | закрывается верхний слой, приложение не теряет незавершённый контекст |
| Живая смена мастера | Реальный маршрут: люди → линия → событие → заявка/мойка → передача | действия понятны, factory/department scope не нарушается |

Не выполнять reset, очистку реальных данных, restore, изменение `.env`, uploads или backups во время этой проверки. Любой найденный дефект фиксировать с ролью, временем, экраном и воспроизводимыми шагами.

Связанный подробный план: [`docs/physical-phone-gate.md`](physical-phone-gate.md).
