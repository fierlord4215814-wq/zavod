# Stage64 — журнал архива чек-листов

## Discovery result

Архив чек-листов уже жил в существующем `ChecklistsModule`: `ChecklistRun`, `ChecklistRunRow`, typed rows Stage44/50/63, `CHECKLIST_RUN_ROW` attachments и endpoint `archive/by-template`. Новый модуль и новая таблица не нужны. Данные для журнала собираются read-only из закрытых запусков чек-листов.

Что переиспользовано:

- `ChecklistTemplate` и `ChecklistTemplateRow` для структуры колонок и порядка пунктов;
- `ChecklistRun.shiftDate`, `shiftType`, `closedAt`, `userId`, `lineId`, `status`;
- `ChecklistRunRow` для значений, комментариев, статусов и норм;
- `AttachmentsService.listForEntities` для guarded вложений строк;
- `pilotDisplayName` и runtime visibility helpers;
- существующие guards `checklists.archive.read` и factory scope.

Migration не нужна: группировка по дате/смене, детали запуска и матрица вычисляются из текущих данных.

## Поведение архива

Основной путь теперь такой:

1. Открыть `Чек-листы`.
2. В библиотеке или доступных чек-листах нажать `Архив` у конкретного шаблона.
3. По умолчанию открывается журнал этого шаблона, сгруппированный по дате и смене.
4. Строка журнала открывает read-only детали конкретного запуска.

Матрица результатов сохранена как вторичный режим `Таблица`.

## Группировка

Журнал группирует закрытые runs по:

- производственной дате смены;
- типу смены: `День` / `Ночь`;
- конкретному шаблону чек-листа.

В строке запуска показываются:

- время закрытия;
- кто заполнил;
- линия;
- статус;
- количество отклонений;
- количество фото;
- количество комментариев.

Для shift date используется московская производственная дата, чтобы запись `2026-06-06T21:00Z` отображалась как `07.06.2026`, а не съезжала на предыдущий день.

## Детали запуска

Детали запуска показывают:

- название чек-листа;
- смену, время, линию и сотрудника;
- статус;
- количество отклонений, фото и комментариев;
- пункты в порядке шаблона.

Для каждого пункта видны:

- название;
- тип;
- значение;
- единица измерения и норма для числовых пунктов;
- статус `Норма`, `Отклонение`, `Не заполнено`;
- комментарий;
- guarded preview вложений.

## Матрица

Режим `Таблица` оставлен для руководителя, которому нужно быстро сравнить несколько запусков одного шаблона. На desktop это сетка, на mobile строки остаются карточными и не становятся главным сценарием.

## Отклонения и фильтры

Отклонением считается:

- `ChecklistRunRow.status = ISSUE`;
- числовое значение вне `min/max`, если такое значение есть в данных;
- незаполненный обязательный ответ;
- отсутствующий обязательный комментарий;
- отсутствующее обязательное фото.

Фильтры:

- период;
- смена;
- линия;
- сотрудник;
- статус;
- только отклонения;
- только с фото;
- только с комментариями.

## Вложения

Фото и файлы строк чек-листа отображаются через общий `AttachmentPreviewList`:

- `storagePath` не возвращается;
- скачивание и просмотр идут через guarded endpoint;
- фото можно открыть в fullscreen viewer;
- недоступный файл показывает русскую ошибку.

## RBAC / Security

Архив не расширяет доступ:

- `ADMIN` видит всё в выбранном заводе;
- `MANAGEMENT` видит свой scope;
- обычный работник не видит чужой архив;
- blocked и cross-factory пользователи denied;
- Stage/test шаблоны скрыты из обычного pilot runtime журнала;
- API не отдаёт `storagePath`, `passwordHash`, tokens или secrets.
