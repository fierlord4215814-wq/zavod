# Stage40A — единый архив

## Discovery

Существующие модули уже хранят историю внутри своих таблиц: заявки, чек-листы, ОКК, возвраты, некондиция, заказы/остатки, мойка, оттайка, пересменка, объявления, чаты и вложения. Stage40A не создаёт новую таблицу истории и не переносит файлы. Раздел `Архив` читает существующие сущности через агрегирующий backend endpoint.

## Принцип хранения

Архив — это единый просмотрщик. Исходные записи остаются в своих таблицах, а вложения остаются в существующем attachment storage. `storagePath` не возвращается в API архива; скачивание остаётся через guarded endpoint вложений.

## Папки архива

- Заявки и простои
- Чек-листы
- ОКК
- Возвраты на производство
- Некондиция
- Заказы / Остатки
- Мойка
- Оттайка
- Пересменка / Журнал
- Объявления
- Файлы и вложения

## Права

Архив не расширяет доступ. Если пользователь не видит объект в исходном разделе, он не видит его в архиве. Общий архив недоступен гостю. Все запросы scoped выбранным заводом.

Примеры:

- `WORKER` видит только разрешённые разделы, например свои доступные возвраты и объявления.
- `STORE` видит складские архивы: возвраты, некондицию, заказы/остатки.
- `OKK` видит архив ОКК, но не получает складское управление.
- `TECH_HOLOD` видит оттайку и доступные заявки.
- `MANAGEMENT` ограничен своим scope.
- `ADMIN` видит все папки.

## Файлы и вложения

Папка `Файлы и вложения` читает metadata `Attachment`, но показывает только вложения, чей исходный объект доступен пользователю. Вложения сообщений чата видны только пользователям, которым доступен этот чат. Вложения архивных ОКК/возвратов показываются по исходным правам `okk.read` / `returns.read`.

## Простые метрики заказов

Для `Заказы / Остатки` Stage40A добавляет только лёгкие суммы за период:

- израсходовано за период = сумма движений `TAKE`;
- пополнено за период = сумма движений `RESTOCK`.

Это не складская аналитика и не учёт себестоимости.

## Что не входит

- глубокая аналитика простоев;
- BI по всем разделам;
- перенос файлов или данных в новую таблицу;
- второй модуль заявок, ОКК, чек-листов или чатов;
- 1С/ERP/product accounting/партии/цены/себестоимость.

## Regression

Добавлены:

- `stage40a:archive-center-regression`;
- `stage40a:browser-e2e`.

Проверяется:

- видимость папок по ролям;
- отсутствие доступа у гостя;
- запрет прямого доступа к чужой папке;
- фильтр вложений по source visibility;
- скрытие `storagePath`;
- TAKE/RESTOCK метрики;
- date filter и pagination;
- mobile 360px для Archive UI;
- русский UI без mojibake и browser dialogs.

## Future

Stage40B может добавить аналитику простоев и более глубокие разборы по линиям. Stage40C может расширить ссылки из архива на detail views там, где сейчас есть только переход к исходному разделу.
