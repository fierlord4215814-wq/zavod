# Stage49 — Архив прошлых смен

## Назначение

Stage49 доводит вкладку **Прошлые** в экране **Смена** до read-only архива смен. Это не новый модуль смен и не BI-отчет: экран помогает мастеру быстро понять, что было на прошлой смене, кто работал, какие линии запускались, где были простои, какие заявки и мойки были связаны со сменой, и что осталось в пересменке.

## Discovery Result

Миграция не понадобилась. Исторический срез собирается из существующих данных:

- `ShiftSession` — кто был на смене и мастера, если они есть в интервале смены.
- `Assignment` — кто где стоял, включая линию, позицию, слот и повременщиков.
- `LineShiftWorkPlan` — текущее задание линии на дату и тип смены.
- `LineEvent` — простои `PAUSE` / `STOP` с effective time из Stage40B.
- `Task` / `TaskHistory` — заявки, созданные в интервале смены или явно связанные с простоем через `lineStatusEventId`.
- `WashSession` / issues / control / OKK review — мойки в интервале смены.
- `ShiftLog` — записи пересменки с человекочитаемым названием отдела.

Связь с прошлой сменой строится по `shiftDate + shiftType` и окну времени:

- день: `08:00–20:00`;
- ночь: `20:00–08:00`;
- ночная смена относится к дате начала ночной смены.

## API

Добавлены read-only endpoints:

- `GET /shift/past` — список прошлых смен с карточками и счетчиками.
- `GET /shift/past/:shiftKey` — детали смены, где `shiftKey = YYYY-MM-DD_DAY|NIGHT`.

Старые поля `sessions` и `assignments` в `/shift/past` сохранены для совместимости. Новое поле `shifts` используется UI Stage49.

## UI

Вкладка **Прошлые** теперь показывает:

- список смен по датам, день/ночь, мастера, линии, простои и заявки;
- detail по выбранной смене;
- вкладки: **Обзор**, **Люди**, **Линии**, **Простои**, **Заявки**, **Мойка**, **Пересменка**.

## Read-only Policy

В прошлом режиме запрещены operational controls:

- назначить;
- освободить;
- домой;
- на мойку;
- запустить линию;
- остановить;
- простой;
- вернуть в работу;
- создать заявку из простоя;
- редактировать текущее задание.

Разрешены только безопасные read-only действия: раскрыть детали, открыть профиль/источник по правам, просмотреть или скачать вложение через guarded endpoint.

## RBAC / Scope

Архив смен не расширяет доступ:

- `ADMIN` видит выбранный завод;
- `MASTER` / `MANAGEMENT` видят заводской срез по своим правам;
- обычный сотрудник видит собственный исторический контекст без управленческих действий;
- blocked и cross-factory доступы отклоняются;
- `storagePath`, секреты, password hash и token не возвращаются.
