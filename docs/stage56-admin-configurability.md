# Stage56 — Admin Configurability / Factory Setup Foundation

## Discovery result

Существующий контур уже содержал модели `Factory`, `Department`, `UserFactoryAccess`, `Line`, `LinePosition`, `LineStaffingTemplate`, `LineStaffingTemplateItem`, `WorkArea`, `WorkAreaPosition`, factory context endpoint и русскую матрицу прав. Read-only foundation Stage53 уже показывал выбранный завод, пользователей с доступом, локальные отделы, общие службы, линии, шаблоны, рабочие зоны, настройки и аудит.

Gap Stage56 был не в отсутствии данных, а в управляемости: админка показывала структуру, но обычный администратор не мог удобно создать/изменить линию, позицию, шаблон состава, рабочую зону, позицию рабочей зоны, отдел/службу и человекочитаемую должность без прямого обращения к коду/API.

## Migration

Добавлена safe additive migration `20260603120000_stage56_admin_configurability` с моделью `JobTitle`.

`JobTitle` — это foundation справочник должностей:

- человекочитаемое название;
- код;
- базовая системная роль;
- отдел/служба;
- permission preset текстом;
- активность/soft deactivate.

Системные роли и `UserFactoryAccess` остаются источником фактических прав. Stage56 не переписывает RBAC и не создаёт custom role architecture.

## Что теперь настраивается

Администратор может через UI и backend guards:

- создать линию выбранного завода;
- переименовать линию;
- отключить/восстановить линию без физического удаления;
- добавить позицию линии;
- отключить/восстановить позицию линии;
- создать шаблон состава с первой строкой позиции;
- отключить/восстановить шаблон состава;
- создать локальный отдел выбранного завода;
- создать общую службу;
- отключить/восстановить отдел/службу;
- создать рабочую зону для повременщиков;
- добавить позицию рабочей зоны с минимумом/планом/максимумом;
- отключить/восстановить рабочую зону и её позиции;
- создать должность foundation;
- выдать пользователю доступ к конкретному заводу с ролью и отделом/службой.

## Линии, позиции и шаблоны

Линия принадлежит выбранному заводу. Отключение линии выставляет soft state и скрывает её из рабочих экранов, но не удаляет историю смен, назначений, простоев и заявок.

Позиция линии хранит название, короткое имя, `skillCode`, порядок и признаки extra/shortage. Отключение позиции не удаляет старые назначения и навыки.

Шаблон состава хранит строки позиций с минимумом, планом и максимумом. Новые смены используют актуальные активные шаблоны; старая история не переписывается.

## Рабочие зоны

Рабочая зона не является производственной линией, не меняет статус линии и используется для повременщиков/подсобных работ. Позиции рабочей зоны имеют минимум, план и максимум. Назначения остаются только для `WORKER`/`CONTRACTOR` в runtime flow.

## Отделы и службы

Локальный отдел относится к выбранному заводу. Общая служба имеет `scope=GLOBAL`, но не выдаёт сотрудникам доступ ко всем заводам. Доступ пользователя по-прежнему задаётся через `UserFactoryAccess` для конкретного завода.

## Должности и роли

Stage56 добавляет foundation справочник должностей, но не заменяет системные роли. Например, должность “Электрик” может быть связана с базовой ролью `TECH_ELECTRIC`, службой “Электрики” и preset “Электрик”. Фактический доступ к Заводу 4 или Заводу 5 выдаётся отдельно в профиле пользователя.

## Пользователи и доступы

В профиле/разделе пользователей администратор видит доступы по заводам и может выдать доступ к выбранному заводу. Last-admin guard сохранён. Заблокированные пользователи не получают runtime context.

## Права

Матрица прав остаётся русской: права сгруппированы по модулям, technical code спрятан в `title`, а основным текстом показывается человекочитаемое название. Stage56 не делает большой wizard прав.

## Audit / safety

Опасные действия идут через `AdminConfirmDialog`. Все изменения пишут audit:

- `LINE_CREATED`, `LINE_UPDATED`, `LINE_DEACTIVATED`, `LINE_REACTIVATED`;
- `LINE_POSITION_CREATED`, `LINE_POSITION_UPDATED`, `LINE_POSITION_DEACTIVATED`, `LINE_POSITION_REACTIVATED`;
- `STAFFING_TEMPLATE_CREATED`, `STAFFING_TEMPLATE_UPDATED`, `STAFFING_TEMPLATE_DEACTIVATED`;
- `WORK_AREA_CREATED`, `WORK_AREA_UPDATED`, `WORK_AREA_DEACTIVATED`;
- `WORK_AREA_POSITION_CREATED`, `WORK_AREA_POSITION_UPDATED`, `WORK_AREA_POSITION_DEACTIVATED`;
- `DEPARTMENT_CREATED`, `DEPARTMENT_UPDATED`, `DEPARTMENT_DEACTIVATED`, `DEPARTMENT_REACTIVATED`;
- `JOB_TITLE_CREATED`, `JOB_TITLE_UPDATED`, `JOB_TITLE_DEACTIVATED`;
- `FACTORY_ACCESS_GRANTED`, `FACTORY_ACCESS_REVOKED`, `USER_FACTORY_ROLE_CHANGED`.

Ответы не должны содержать `storagePath`, `passwordHash`, токены или secrets.
