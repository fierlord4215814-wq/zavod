# Одна очередь решений на checkpoint R5

R5 разрешил установку одного test isolation mechanism; старый вопрос R4 «разрешена ли установка вообще?» закрыт. Осталась отменённая конкретная UAC-попытка и неподтверждённый полный Windows10 guest stack. Product policies ниже НЕ утверждены и не блокируют независимые gates после появления среды.
