Разрешённый существующий диск:

Этим поручением разрешаю ОДНУ диагностическую загрузку существующей установленной системы с этого VHDX, даже если завершённость установки Ubuntu пока не доказана.

Цель загрузки — получить текстовый доступ и проверить систему, а не объявить её готовой.

Это заменяет прежнее условие «сначала полностью проверить Ubuntu, потом разрешить её загрузку» только для данной диагностической попытки.

Обычная загрузка может изменять гостевые журналы и служебное состояние. Она НЕ разрешает разметку, форматирование, повторный autoinstall, восстановление из образа или стирание диска.

Перед изменениями:
— проверить VM по GUID;
— проверить фактическое состояние и отсутствие другого управляющего процесса;
— проверить единственный подключённый VHDX и его точный путь;
— сохранить текущую конфигурацию firmware, дисков, DVD и сети;
— проверить, что нет рабочей БД, host-дисков или чужих ресурсов среди подключений.

Если VM сейчас Running, не выключать её ради выполнения этого раздела: сначала проверить разрешённое текстовое подключение. Не применять Force/TurnOff/Reset.

Если VM Off:
— временно извлечь ТОЛЬКО собственные Ubuntu ISO и CIDATA seed из виртуальных DVD, сохранив сами файлы и исходные пути;
— выбрать существующий VHDX первым загрузочным устройством штатными Hyper-V cmdlets;
— сохранить Secure Boot и остальные не относящиеся к действию настройки;
— проверить результат конфигурации;
— запустить именно эту VM один раз.

Не создавать новую VM, VHDX или switch.
Не повторять DISM.
