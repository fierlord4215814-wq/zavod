## Общий workbook contract

- Русские headers; freeze первой строки; AutoFilter; widths/wrap; один workbook на selection.
- Typed dates/numbers/durations; `Да/Нет`; human labels/statuses; «Параметры» всегда последний.
- Canonical source reads выполняются детерминированными пакетами по 1000; detail enrichment — пакетно, без HTTP N+1.
- При 1 048 575 data rows таблица продолжается на следующем листе того же workbook без потери строк.
- Пустая выборка сохраняет основной лист с headers и нулевым количеством в «Параметрах».
