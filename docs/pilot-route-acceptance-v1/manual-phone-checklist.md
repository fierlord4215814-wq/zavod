# Ручная проверка на физическом телефоне

Статус: `PHYSICAL_PHONE_GATE: PENDING`. Этот список не блокирует программную route acceptance, но обязателен перед завершением живого пилота.

1. Открыть приложение на реальном Android/iOS при ширине 360–390 px и войти pilot-пользователем.
2. Установить PWA штатным действием браузера; закрыть и повторно открыть приложение с иконки.
3. Проверить online/offline-переход: понятное состояние без белого экрана и без потери уже введённого текста.
4. Разрешить push, получить реальное уведомление, открыть связанный экран нажатием.
5. Проверить вибрацию уведомления там, где устройство и браузер её поддерживают.
6. В чате записать и воспроизвести короткое голосовое сообщение; отказ в разрешении микрофона должен быть понятным.
7. Сделать фото камерой и приложить его к разрешённому рабочему сценарию; проверить просмотр и закрытие preview.
8. Проверить выбор нескольких файлов из галереи и возврат к форме без потери полей.
9. Открыть клавиатуру в длинной форме: sticky action и bottom navigation не должны перекрывать активное поле.
10. Пройти один живой маршрут мастера: текущая смена → люди → линия → простой/заявка → передача смены.
11. Проверить смену роли/blocked состояния на уже открытом телефоне: недоступные экраны должны исчезнуть без повторного входа, прямой запрос — получить deny.
12. После проверки закрыть диагностические записи штатным действием; реальные данные и uploads физически не удалять.

Результат каждого пункта фиксировать как `PASS`, `FAIL` или `N/A` с моделью телефона, ОС, браузером и временем проверки.
