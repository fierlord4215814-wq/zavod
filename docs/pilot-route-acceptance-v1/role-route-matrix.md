# Матрица ролей и пилотных маршрутов

Дата свежего прогона: 16.07.2026. Матрица фиксирует проверенный пользовательский доступ, а не заменяет backend guards.

Обозначения: `Д` — действие разрешено в своём factory/department scope; `П` — просмотр; `—` — маршрут не предназначен роли или backend возвращает запрет.

`Д*` означает ограниченное управление только внутри собственного отдела/иерархии и только подмножеством собственных полномочий. ADMIN сохраняет полный административный сценарий. Любой blocked/deactivated пользователь и любой запрос вне доступного завода отклоняется backend.

Проверенные deny-классы: ordinary user → statistics/audit/admin; чужой отдел → делегирование/закрытый чат/назначение; чужой завод → рабочие данные; blocked/deactivated → runtime endpoints; получатель вне scope → изменение чужой записи.
