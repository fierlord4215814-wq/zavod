# REST API Contracts

## Auth
- `POST /auth/login`

## Shift
- `POST /shift/start`
- `POST /shift/end`

## Lines
- `GET /lines`
- `POST /lines/status` (requires comment when `PAUSE`)

## Assignments
- `POST /assignments`

## Tasks
- `POST /tasks`
- `PATCH /tasks`

## Wash
- `POST /wash/start`
- `POST /wash/issue`

## OKK
- `POST /okk`

## Stock Defects
- `POST /stock-defects`

## Logs
- `POST /logs`

## Checklists
- `POST /checklists`
