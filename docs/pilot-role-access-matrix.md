# Матрица доступа мобильного пилота v1.0

Статус: подтверждено автоматическими backend/browser проверками Пластов 1-6.

## Источник истины

- Backend permissions, guards, `UserFactoryAccess`, factory/department/company scope являются источником истины.
- Канонический каталог экранов и permission-driven меню: `frontend/src/navigation/permissions.ts`.
- `frontend/src/App.tsx` и предпросмотр роли в админке используют один `SCREEN_DEFINITIONS` и `canShowScreen`.
- Скрытие пункта меню не заменяет backend deny. Прямые маршруты и API проверены отдельно.

## Роли

| Роль | Основной доступ | Критичные ограничения |
| --- | --- | --- |
| Гость | «Сообщить об ошибке», заявка назначения | Нет объявлений, производственных и административных модулей |
| WORKER | Своя смена/люди в упрощённом режиме, оттайка, чаты, объявления, уведомления, личный архив, ошибка | Нет управления людьми/линиями, чек-листов, возвратов, качества, заказов и статистики |
| CONTRACTOR | Собственный статус и назначение текущей смены, ошибка | Нет внутренних производственных модулей, возвратов и чек-листов |
| CONTRACTOR_LEAD | Своя фирма, текущий/будущий план и факт работников, ошибка | Только своя фирма и завод; нет линий, внутренних заявок, чек-листов и чужих компаний |
| MASTER | Управление разрешённой сменой, людьми, линиями и назначениями; возвраты и рабочие модули по permissions | Только доступные завод/отдел; не может выдавать права выше собственных |
| Senior master | Возможности мастера и разрешённое делегирование нижестоящим | Иерархия должностей и subset прав проверяются backend |
| TECH_* | Read-only обзор смены/линий/людей и заявки своей службы по permissions | Нет управления людьми/линиями без явного permission |
| TECHNOLOG | Технологические маршруты и разрешённое управление своим отделом | Нет автоматического cross-department/cross-factory |
| OKK | Контур качества, разрешённые заявки/мойка/возвраты/чек-листы | Scope завода и отдела сохраняется |
| STORE | Свободные люди/повременщики, возвраты, журнал и коммуникации | Нет «Заказы / Остатки», некондиции, оттайки и полного assignment workspace |
| OTHER | Только явно назначенные права и общие безопасные действия | Название роли/отдела не расширяет доступ автоматически |
| MANAGEMENT | Управленческие разделы, статистика и аудит в доступных заводах | Нет чтения завода без активного `UserFactoryAccess` |
| ADMIN | Полный административный сценарий и все экраны | Last-admin guard, audit, blocked/deactivated и factory scope остаются обязательными |

## Подтверждённые запреты

- Guest видит только форму ошибки; legacy `guestCanRead` не даёт объявления.
- WORKER и CONTRACTOR не получают возвраты, чек-листы, admin или analytics.
- STORE не получает остатки/заказы, но сохраняет разрешённые возвраты.
- Обычный пользователь не открывает admin/statistics прямым API.
- Делегирование не добавляет права сверх пересечения с правами выдающего.
- Cross-factory, cross-department и cross-company spoof запрещены backend.
- Blocked/deactivated пользователь не получает рабочий контекст.
